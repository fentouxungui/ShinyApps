ShinyApps Store User Guide

ShinyApps Store is a lightweight desktop app store for R / Shiny applications. The installed program (the shell) provides a launcher, a shared R runtime and an installer. Individual apps are downloaded on demand from an online catalog, so new apps appear without reinstalling ShinyApps Store.

1. Getting ShinyApps Store

Download

Go to the Releases page: github.com/fentouxungui/ShinyApps/releases

  • Windows: download shinyapps-Setup-<version>-x64.exe.
  • macOS (Apple silicon): download the .dmg.

Install

  • Windows: run the installer; you may choose the installation folder.
  • macOS: open the .dmg and drag ShinyApps Store into Applications.

First launch (unsigned builds)

  • Windows: SmartScreen may show "Windows protected your PC" → More info → Run anyway.
  • macOS: Gatekeeper may block it → right-click the app → Open, or allow it in System Settings → Privacy & Security.

2. Updating ShinyApps Store (the shell)

  • ShinyApps Store checks for a new shell version at startup and downloads it automatically.
  • Automatically installing an update requires a signed build. On unsigned builds the update can be downloaded but Windows/macOS will refuse to apply it — update by re-running the latest installer from Releases.
  • Your installed apps and settings are kept across updates.

3. The launcher at a glance

  • The left sidebar has Discover / My Apps / Updates / Running / Installing; Install… and Settings are at the bottom.
  • Discover opens first when nothing is installed; returning users open My Apps.
  • Browse by category in the sidebar; the list shows version, size and status.
  • Search all apps by name, description or author (Ctrl/Cmd+F or Ctrl/Cmd+K); results are not limited to the current section.
  • Sort (Name / Recently used / Most used) and Favorites are in the toolbar.
  • Toggle Cards / List layout (remembered). Click an app name for its detail drawer.
  • Apps → Quick Run lists favorites / most-used first.

4. Installing apps

From the catalog

  1. Find the app and click Install.
  2. The card shows live progress: download % → verify → install.
  3. When it finishes, the card shows Run.

From a file

Install… → From file… at the bottom of the sidebar (or Apps → Install from Bundle…), then pick a *.zip bundle.

From a URL

Install… → From URL… (or Apps → Install from URL…), paste a direct link to a bundle .zip.

Downloads are resumable and verified (size + SHA-256) before installing. Up to two installs download at once; extra requests queue. You can keep browsing and running apps while they work. The Installing section shows progress and a Cancel action for each app.

5. Running apps

  • Click Run (or Open if already loaded). Only one app runs at a time; the other Run buttons are disabled until you stop it.
  • The app opens in its own window with a slim Store / Stop toolbar at the top; the store stays open.
  • Clicking the store window keeps the app running. Closing the app window stops it after an unsaved-work confirmation.

6. Updating apps

  • On every launch, ShinyApps Store compares each installed app with the catalog.
  • If a newer version exists, the Updates section shows the count and the card shows Update. Use Update all for several apps; downloads continue in the background.
  • Updating an app does not touch your app data.

7. Uninstalling apps

  • Open the app's … menu → Uninstall (or the detail drawer), then confirm.
  • This removes the installed copy and its private packages. Your app data is kept.
  • To remove ShinyApps Store itself, see section 12.

8. Storage and clean-up

  • Settings (sidebar) → Storage… shows installed apps, shared packages, download cache, incomplete items and free disk.
  • Clean up removes the download cache and unused shared packages.
  • Open folder opens the data directory in your file manager.
  • Reset local data… removes all installed apps, shared packages, caches and logs (settings are kept); a progress overlay is shown.

9. Changing the app data directory

By default, apps and data live under %LOCALAPPDATA%\ShinyApps (Windows) or the app's application-support folder (macOS). To move them:

  1. Settings (sidebar) → App data location… (or Storage… → Change data location…).
  2. Choose a folder.
  3. Move existing data (copies apps and libraries) or Use empty folder (start fresh). If the folder already holds ShinyApps Store data: Use existing data or Overwrite with current data.
  4. ShinyApps Store restarts to apply the change.

10. Appearance and privacy

  • Settings (sidebar) → Appearance: System / Light / Dark.
  • Settings (sidebar) → Save crash reports locally: writes crash reports to the local crashes folder. They are never uploaded automatically.

11. Logs and diagnostics

  • Help → View Logs opens the log folder.
  • Per app, the … menu offers View log, Open app folder, Copy diagnostics.
  • Logs (and crash reports) are the first thing to include when reporting a problem.

12. Uninstalling ShinyApps Store

  • Settings (sidebar) → Local data → Uninstall ShinyApps….
  • Choose Uninstall (keep apps & data) or Uninstall and remove all apps & data.
  • If ShinyApps Store was not installed from a release, no uninstaller exists — remove the app folder manually.

13. Reporting a bug / getting help

  1. Reproduce the problem and note exactly what you did and what happened.
  2. Help → View Logs; copy the relevant log, plus any crash report from the crashes folder.
  3. Open an issue: github.com/fentouxungui/ShinyApps/issues with:
    • ShinyApps Store version (Help → About) and your OS;
    • the app name/version if app-specific;
    • steps to reproduce, expected vs. actual;
    • the relevant log excerpt.

14. Keyboard shortcuts

ShortcutAction
Ctrl/Cmd+F / Ctrl/Cmd+KFocus search
Ctrl/Cmd+Shift+MMy Apps
EscClose a dialog or the app detail drawer

15. Where things are stored

  • Data root (changeable in Settings): Windows %LOCALAPPDATA%\ShinyApps; macOS the app support folder.
  • apps/<id>/ each installed app · lib/ shared packages · private/ app-private packages · store-cache/ download cache · state.json state.
  • Logs and crash reports live in the shell's user-data folder (logs/, crashes/).

16. Glossary

  • Shell — the installed ShinyApps Store program.
  • Catalog — the online list of available apps.
  • Bundle — a <id>-<version>-<platform>.zip holding app/ + rlib/ + manifest.json.
  • Shared library — packages used by two or more apps, stored once.

ShinyApps Store 是一个轻量的桌面 R / Shiny 应用商店。已安装的程序（外壳）提供启动器、 共享 R 运行时和安装器；各个应用从在线目录按需下载，因此新增应用无需重新安装 ShinyApps Store。

1. 获取 ShinyApps Store

下载

打开 Releases 页面：github.com/fentouxungui/ShinyApps/releases

  • Windows：下载 shinyapps-Setup-<版本>-x64.exe。
  • macOS（Apple 芯片）：下载 .dmg。

安装

  • Windows：运行安装程序，可选择安装目录。
  • macOS：打开 .dmg，把 ShinyApps Store 拖入 应用程序。

首次启动（未签名版本）

  • Windows：SmartScreen 可能提示“Windows 已保护你的电脑” → 更多信息 → 仍要运行。
  • macOS：Gatekeeper 可能拦截 → 右键应用 → 打开，或在 系统设置 → 隐私与安全性 中放行。

2. 更新 ShinyApps Store（外壳）

  • 启动时会检查是否有新的外壳版本并自动下载。
  • 自动安装更新需要已签名构建。未签名版本能下载更新，但 Windows/macOS 会拒绝应用 — 请从 Releases 重新运行最新安装程序来更新。
  • 更新不会影响已安装的应用与设置。

3. 启动页导览

  • 左侧栏包含 Discover / My Apps / Updates / Running / Installing；底部是 Install… 和 Settings。
  • 没有已安装应用时默认进入 Discover；已有应用时默认进入 My Apps。
  • 通过左侧分类浏览；列表会显示版本、大小和状态。
  • 搜索全部应用（名称、描述或作者，Ctrl/Cmd+F 或 Ctrl/Cmd+K）；结果不限于当前 section。
  • 排序（名称 / 最近使用 / 最常用）和收藏在工具栏。
  • 切换卡片 / 列表布局（会记住）。点击应用名称打开详情抽屉。
  • Apps → Quick Run 把收藏 / 最常用排在前面。

4. 安装应用

从目录安装

  1. 找到应用，点击 Install。
  2. 卡片显示实时进度：下载 % → 校验 → 安装。
  3. 完成后卡片显示 Run。

从文件安装

Install… → From file…（左侧栏底部）或 Apps → Install from Bundle…，选择 *.zip 捆绑包。

从 URL 安装

Install… → From URL…（或 Apps → Install from URL…），粘贴捆绑包 .zip 的直接链接。

下载支持断点续传，并在安装前校验（大小 + SHA-256）。最多两个安装任务同时下载，其余排队； 下载期间可以继续浏览和运行应用。Installing 页显示每个应用的进度和 Cancel。

5. 运行应用

  • 点击 Run（若已加载则显示 Open）。同一时刻仅运行一个应用；其它 Run 按钮会被禁用，直到停止当前应用。
  • 应用在独立窗口中打开，顶部有 Store / Stop 细工具栏，商店保持可用。
  • 点击商店窗口不会停止应用；关闭应用窗口会在确认未保存内容后停止它。

6. 更新应用

  • 每次启动都会把已安装应用与目录对比。
  • 若有新版本，侧栏 Updates 显示数量，卡片显示 Update。多个应用可用 Update all，下载在后台继续。
  • 更新应用不会动到你的应用数据。

7. 卸载应用

  • 打开应用的 … 菜单 → Uninstall（或详情抽屉），然后确认。
  • 会移除已安装副本及其私有包，你的应用数据会保留。
  • 卸载 ShinyApps Store 本身见第 12 节。

8. 存储与清理

  • Settings（侧栏）→ Storage… 显示：已安装应用、共享包、下载缓存、未完成项、可用磁盘。
  • Clean up 清除下载缓存与未使用的共享包。
  • Open folder 在文件管理器中打开数据目录。
  • Reset local data… 移除所有已安装应用、共享包、缓存与日志（设置保留）；过程中显示进度遮罩。

9. 修改应用数据目录

默认数据位于 %LOCALAPPDATA%\ShinyApps（Windows）或应用的支持目录（macOS）。迁移方式：

  1. Settings（侧栏）→ App data location…（或 Storage… → Change data location…）。
  2. 选择目标文件夹。
  3. 选 Move existing data（复制应用与库）或 Use empty folder（全新开始）。 若目标已有 ShinyApps Store 数据：Use existing data 或 Overwrite with current data。
  4. ShinyApps Store 会重启以生效。

10. 外观与隐私

  • Settings（侧栏）→ Appearance：System / Light / Dark。
  • Settings（侧栏）→ Save crash reports locally：把崩溃报告写入本地 crashes 目录，绝不自动上传。

11. 日志与诊断

  • Help → View Logs 打开日志目录。
  • 每个应用的 … 菜单提供 View log、Open app folder、Copy diagnostics。
  • 报告问题时，请优先附上日志（与崩溃报告）。

12. 卸载 ShinyApps Store

  • Settings（侧栏）→ Local data → Uninstall ShinyApps…。
  • 可选 Uninstall（保留应用与数据）或 Uninstall and remove all apps & data。
  • 若 ShinyApps Store 不是通过安装包安装（如从源码运行），没有卸载器 — 请手动删除程序目录。

13. 报告 Bug / 获取帮助

  1. 复现问题，记录你的操作与现象。
  2. Help → View Logs；复制相关日志，以及 crashes 目录中的崩溃报告。
  3. 到 github.com/fentouxungui/ShinyApps/issues 提交 Issue，附：
    • ShinyApps Store 版本（Help → About）与操作系统；
    • 涉及具体应用时，附应用名 / 版本；
    • 复现步骤、期望结果与实际结果；
    • 相关日志片段。

14. 快捷键

快捷键操作
Ctrl/Cmd+F / Ctrl/Cmd+K聚焦搜索框
Ctrl/Cmd+Shift+M打开 My Apps
Esc关闭对话框或应用详情抽屉

15. 数据存放位置

  • 数据根目录（可在设置中修改）：Windows %LOCALAPPDATA%\ShinyApps；macOS 为应用支持目录。
  • apps/<id>/ 各应用 · lib/ 共享包 · private/ 应用私有包 · store-cache/ 下载缓存 · state.json 状态。
  • 日志与崩溃报告位于外壳的用户数据目录（logs/、crashes/）。

16. 术语表

  • 外壳（Shell） — 已安装的 ShinyApps Store 程序。
  • 目录（Catalog） — 在线可安装应用列表。
  • 捆绑包（Bundle） — 含 app/ + rlib/ + manifest.json 的 <id>-<版本>-<平台>.zip。
  • 共享库 — 被两个及以上应用使用的包，只存一份。
